# Security Policy

## Supported versions

Only the latest commit on `main` is supported with security fixes. There are no versioned releases yet.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report it privately through GitHub Security Advisories:

https://github.com/mki169/bettermathtype/security/advisories/new

Please include:

- a description of the issue and its impact
- steps to reproduce, including the equation and browser when relevant
- the affected commit or version
- any suggested fix or mitigation

## Scope

This is a client-side application. Areas of interest include:

- cross-site scripting or unsafe HTML/SVG handling
- clipboard or file-export issues
- dependency vulnerabilities
- deployment configuration mistakes

## Response

I aim to acknowledge reports within 7 days and will coordinate a fix and disclosure through the GitHub advisory. Please allow a reasonable window for a fix before public disclosure.

This project does not offer a bug bounty. Thank you for reporting responsibly.
